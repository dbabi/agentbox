# agentbox: Build Plan (v5.3, matches ARCHITECTURE.md v5.3)

**What we're building:** stock Ubuntu Server 26.04 plus one verified install. The box runs AI agents as well as t3os or Omarchy do, and it is also safe to leave unattended with real credentials.

**Where the details live:** every technical decision and its evidence is in `ARCHITECTURE.md` (§17 maps every review finding to its fix). `LEDGER.md` gives each of the 154 round-5 findings one end state. This file covers only the order of work and the gates. The v5.3 proposals, their gate texts (A-G*, B-G*, C-G*, D-G*, X-G*) and the decisions behind them are in `PROPOSALS-v5.3.md`; ARCHITECTURE §17 Round 6 lists what v5.3 adopted (A–D) and rejected (E, the delivery lane). v5.2 is kept as `PLAN-v5.2.md`.
